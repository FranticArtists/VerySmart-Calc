- absolute
- relative
- maximum error
- number of significant digits
given an approximation p* of p.

## Formulas

- Absolute Error:
> |p - p*|
- Relative Error:
> |p - p*|/|p|
- Significant Digits:
>|p - p*|/|p| <= 0.5 x 10^(-n+1)
